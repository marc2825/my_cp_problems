解説

まず判定条件を述べます。 次の $2$ つがともに成り立つとき、かつそのときに限り Yes です。

  • すべての $i,j$ について、$S_i < S_j$ ならば $G_i < G_j$
  • $i \neq j$ かつ $G_i = G_j$ ならば $S_i = S_j = G_i$

直感的には、1階ずつ移動させることで多くの状態には到達可能だが、エレベーターは互いに追い越せず、また一旦別々の階に分かれた2台は二度と同じ階に戻れないということを表しています。 以下、この条件の正当性を示します。


基本的な観察

まず、階 $F$ にエレベーターが停止しているとき、$F$ のボタンを押しても配置は変化しません。 距離の最小値が $0$ であり、選べるのは $F$ にいるエレベーターだけだからです。
つまり、別の階にいるエレベーターが、既にエレベーターが存在する階へ移動することはありません。

また、ある時点におけるエレベーター $i$ の現在位置を $p_i$ として、以下の補題が成立します：

[補題 1] （エレベーターの大小関係の不変性）. ある時点で $2$ 台のエレベーター $a,b$ が異なる階にあり、 $p_a=x<y=p_b$ を満たすならば、以後も常に $p_a<p_b$ である。
証明

$F$ 階のボタンを押したとします。

エレベーター $a$ が移動した場合、 $a$ は移動するエレベーターとして選ばれているため、 \[ |x-F|\leq |y-F| \] が成り立ちます。 ここで $F\geq y$ ならば、$x<y$ より \[ |y-F|<|x-F| \] となって矛盾します。したがって $F<y$ であり、 移動後もエレベーター $a$ はエレベーター $b$ より低い階にいます。

同様に、エレベーター $b$ が移動した場合は $F>x$ であるため、 移動後もエレベーター $a$ はエレベーター $b$ より低い階にいます。

$a,b$ 以外のエレベーターが移動した場合は、 $a,b$ の位置は変化しません。 したがって、いずれの場合も $p_a<p_b$ は保たれます。


必要性

条件 (A)：$S_i < S_j$ なら [補題 1] より常に $p_i < p_j$ なので、特に $G_i < G_j$ です。

条件 (B)：$i \neq j$ かつ $G_i = G_j$ とします。 もし途中で $2$ 台が異なる階にいた瞬間があれば、 [補題 1] より最後まで異なる階にいることになり矛盾です。 よって $2$ 台は常に同じ階にいます。 ここで一方が動いたとすると、移動先はエレベーターが存在しない階なので他方とは別の階になってしまいます。また、この階に $2$ 台が合流することもできません。 したがってどちらも一度も動いておらず、$S_i = G_i = S_j = G_j$ です。


十分性

まず、次の補題が成立します：

[補題 2]（$1$ 階ずつの移動）. エレベーター $k$ が階 $q$ にいるとき、階 $q+1$（あるいは $q-1$）がビル内かつ空きならば、$k$ をその階へ移動できる。

証明

$F = q+1$ を押すと、$F$ は空きなので最小距離は $1$ 以上であり、$k$ の距離は $1$ なので $k$ は最小距離を達成します。 よって $k$ を選べばよいです。$q-1$ も同様です。


以下、条件 (A)、(B) が成り立つとして、目的の配置に到達できることを示します。
エレベーターを組 $(S_i, G_i)$ の辞書順にソートして番号を振り直しても一般性は失われないので、ソート後の $i$ 番目の現在位置を $q_i$（初期値は $S_i$）、目標位置を $g_i$ とします。
初期状態では $q_1 \leq \cdots \leq q_M$ であり、$S_i < S_j$ なら $g_i < g_j$ で、$S_i = S_j$ なら $G$ の昇順に並んでいることから、条件 (A) より $g_1 \leq \cdots \leq g_M$ でもあります。
また条件 (B) より、$g_i = g_j\ (i \neq j)$ なる台は $S_i = S_j = G_i$ を満たします。 これらの台は以下の手続きでは一度も動かさないので、常に $q_i = g_i$ が成り立ちます。

次に、ポテンシャル $\Phi = \sum_i |q_i - g_i|$ を考えます。このとき、以下の補題が成立するため、$\Phi$ が $1$ ずつ減り有限回で $0$、すなわち目的の配置に到達します。本問では最小操作回数を求める必要はなく、到達可能性のみを判定すれば良い点に注意してください。

[補題 3]（目標に近づく移動の存在）. $q_i \neq g_i$ なる $i$ が存在するならば、$q_1 \leq \cdots \leq q_M$ を保ったまま $\Phi$ を $1$ 減らす補題 2 の移動が存在する。
証明

目標にまだ到達していないエレベーターを、目標の方向へ $1$ 階だけ動かすことを考えます。

大きい方向（以降、「右」と表現します）へ動く必要があるエレベーターが存在する場合は、その中で最も添字が大きいものを選びます。 そのようなエレベーターが存在しない場合は、小さい方向（以降、「左」と表現します）へ動く必要があるエレベーターの中で最も添字が小さいものを選びます。 それぞれの場合について、進行方向に隣接する階が空いていることを示します。

場合 1：右へ動く必要のあるエレベーターが存在する

$q_k < g_k$ を満たす $k$ のうち、最大のものを選びます。
$k$ より右側、すなわち $j > k$ を満たすエレベーターは、右へ動く必要がありません。 また、目標位置は添字順に非減少です。したがって、

$q_k < g_k \leq g_j \leq q_j$

が成り立ちます。

次に、エレベーター $k$ を、目標の方向である $q_k+1$ 階へ動かすことを考えます。
そのために、$q_k+1$ 階にエレベーターが存在しないことを示します。

$q_k+1$ 階にエレベーター $j$ が存在すると仮定します。
$q_k < q_j=q_k+1$ であり、現在位置は添字順に非減少なので、$k < j$ です。 また、$q_k < g_k$ であり、これらは整数なので $q_k+1\leq g_k$ です。よって、

$q_j=q_k+1\leq g_k\leq g_j\leq q_j$

となり、すべて等号です。特に $g_k=g_j$ が成り立ちます。
しかし、同じ目標階を持つ複数のエレベーターは、仮定の条件 (B) より最初からその目標階にいて、 以後も動かさないものとしていました。 したがって $q_k=g_k$ でなければならず、$q_k<g_k$ に矛盾します。

よって、$q_k+1$ 階にはエレベーターが存在しません。
また、$q_k+1\leq g_k\leq N$ なので、$q_k+1$ 階はビル内です。 以上の証明と [補題 2] より、エレベーター $k$ を $q_k+1$ 階へ、エレベーターが詰まることなく動かせます。

さらに、$k$ より右側のエレベーターは $q_k+1$ 階にはいないため、 移動後も現在位置の順序は保たれます。
結局、エレベーター $k$ は目標へ $1$ 階近づくので、$\Phi$ はちょうど $1$ 減ります。

場合 2：右へ動く必要のあるエレベーターが存在しない

（以下の議論は、場合1 の証明の大小関係を反転させたものであり、流れは一緒です。）
この場合、すべての $i$ について $g_i\leq q_i$ です。
一方、$q_i \neq g_i$ なる $i$ が存在するので、左へ動く必要のあるエレベーターは少なくとも $1$ 台存在します。

$g_k<q_k$ を満たす $k$ のうち、最小のものを選びます。
$k$ より左側、すなわち $j<k$ を満たすエレベーターは、すべてすでに目標位置にいます。 また、目標位置は添字順に非減少です。したがって、

$q_j=g_j\leq g_k<q_k$

が成り立ちます。

エレベーター $k$ を、目標の方向である $q_k-1$ 階へ動かすことを考えます。
そのために、$q_k-1$ 階が空いていることを示します。

仮に、$q_k-1$ 階にエレベーター $j$ がいるとします。
$q_j=q_k-1<q_k$ であり、現在位置は添字順に非減少なので、$j<k$ です。 したがって、$k$ の選び方から $q_j=g_j$ です。
また、$g_k<q_k$ であり、これらは整数なので $g_k\leq q_k-1$ です。よって、

$q_j=g_j\leq g_k\leq q_k-1=q_j$

となり、すべて等号です。特に $g_j=g_k$ が成り立ちます。
しかし、同じ目標階を持つ複数のエレベーターは常にその目標階にいるため、 $q_k=g_k$ でなければなりません。 これは $g_k<q_k$ に矛盾します。

よって、$q_k-1$ 階は空いています。
また、$1\leq g_k\leq q_k-1$ なので、$q_k-1$ 階はビル内です。 [補題 2] より、エレベーター $k$ を $q_k-1$ 階へ動かせます。

さらに、$k$ より左側のエレベーターは $q_k-1$ 階にはいないため、 移動後も現在位置の順序は保たれます。
結局、エレベーター $k$ は目標へ $1$ 階近づくので、$\Phi$ はちょうど $1$ 減ります。

以上より、$q_i \neq g_i$ なる $i$ が存在する限り、現在位置の順序を保ったまま $\Phi$ を $1$ 減らす移動が必ず存在します。


実装

例えば、以下のように判定すると簡潔に実装できます。
組 $(S_i, G_i)$ を辞書順にソートすると、条件 (A)、(B) は隣り合う組だけを見れば判定できます。
具体的には、ソート後の隣接する $2$ 組 $(s_1,g_1), (s_2,g_2)$ について

  • $g_1 > g_2$ ならば No（$G$ が非減少でない）。
  • $g_1 = g_2$ かつ $s_1 = s_2 = g_1$ でないならば No。

を確かめ、すべてで違反しなければ Yes となります。

計算量に関してはソート部分が支配的となり、全体で $O(\sum M \log M)$ で実装できます。
（実装例：C++ (36ms) / PyPy (445ms)）
